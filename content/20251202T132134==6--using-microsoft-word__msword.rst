Using Microsoft Word
====================

Unfortunately I need to use Word a lot as part of my ``$DAYJOB``, so I may as well try and make the most of it!

Multiple Windows
----------------

Word does actually support having multiple windows open on the same document!
Click the :guilabel:`New Window` button in the :guilabel:`View` ribbon.

Inserting...
------------

... Cross-References
^^^^^^^^^^^^^^^^^^^^

Clicking the :guilabel:`Cross-reference` button in the :guilabel:`References` window opens a handy dialog window that can insert cross-references for numbered sections, tables, figures and more. Each with varying degrees of verbosity.

... Document Properties
^^^^^^^^^^^^^^^^^^^^^^^

To insert the value of a document property into a Word document

#. Place the cursor where you want the value to appear in the document

#. In the :guilabel:`Insert` tab in the ribbon find and click the :guilabel:`Quick Parts` button

#. This opens a menu, click :guilabel:`Field...` which will open a dialog

#. In the leftmost column, click the field name ``DocProperty``

#. In the center column, select the property whose value you wish to include and click :guilabel:`Ok`

.. tip::

   To update all tables of contents, fields etc. in the documen, select everything using :kbd:`Ctrl+A` and hit :kbd:`F9`

   **Note:** Fields in the header/footer may not update, generate a print preview to force this.
