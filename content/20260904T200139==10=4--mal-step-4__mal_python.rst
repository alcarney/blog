Special forms
^^^^^^^^^^^^^

A "special form" is anything that is not evaluated using the regular rules of the language and therefore needs dedicated support from the interpreter.

``def!``
""""""""

``def!`` is how ``mal`` spells ``setq`` and updates the current environment

.. code-block:: python
   :in-file: step4_if_fn_do.py
   :in-slot: def

   case S('def!'):
       env.set(fs[1].name, v := evaluate(fs[2], env))
       return v

``do``
""""""

Equivalent to ``progn``, evals all terms and returns the last one.

.. code-block:: python
   :in-file: step4_if_fn_do.py
   :in-slot: do

   case S('do'):
       for f in fs[1:]:
           v = evaluate(f, env)
       return v

``fn*``
"""""""

a.k.a lambda.

I'm surprised at how conceptually simple it is.

A function definition:

- Creates a new ``Env`` as a child of the current environment, it's parameters define names that are yet to have values associated with them.

- When called, these missing values are provided from its arguments and the function then calls evaluate on its body with the new local environment.

.. code-block:: python
   :in-file: step4_if_fn_do.py
   :in-slot: fn

   case S('fn*'):
       def fn(*args):
           localenv = Env(outer=env, binds=fs[1], exprs=args)
           return evaluate(fs[2], localenv)
       return fn

Of course, the fact Python already has closures means that it is doing all the heavy lifting!

This does require us to add support for this to our ``Env`` class.

.. code-block:: python
   :in-file: env.py

   from reader import S

   class Env:
       def __init__(
           self,
           outer: Env | None = None,
           binds: list[str] = None,
           exprs: list[Any] = None,
        ):
           self.data = {}
           self.outer = outer

           binds = binds or []
           exprs = exprs or []
           for b, e in zip(binds, exprs):
               self.set(b.name, e)

       def set(self, key: str, value):
           self.data[key] = value

       def get(self, key: str):
           if (value := self.data.get(key)) is None:
               if self.outer is not None:
                   return self.outer.get(key)
               raise KeyError(key)
           return value


``if``
""""""

``mal`` considers anything that is not ``false`` or ``nil`` to be ``true``.
Python however, considers other values like ``0`` to *also* be False!

This mismatch made implementing if surprinsgly difficult, especially when it likes to coerce ``0`` to ``False`` or ``False`` to ``0``.

The best I have come up with so far is to call ``print_form`` on the result and check the string values.

.. code-block:: python
   :in-file: step4_if_fn_do.py
   :in-slot: if

   case S('if'):
       t = print_form(evaluate(fs[1], env))
       if t not in {'false', 'nil'}:
           return evaluate(fs[2], env)
       if len(fs) > 3:
           return evaluate(fs[3], env)
       return None

``let*``
""""""""

``let*`` is used to introduce a new local ``Env`` with additional bindings.

.. code-block:: python
   :in-file: step4_if_fn_do.py
   :in-slot: let

   case S('let*'):
       letenv = Env(env)
       for binding, expr in itertools.batched(fs[1], n=2):
           letenv.set(binding.name, evaluate(expr, letenv))
       return evaluate(fs[2], letenv)

       return len(x) == 0

   def count(x):
       if not x:
           return 0
       return len(x)

Reader
------

To get the ``mal`` tests to pass the reader needs to tweaked to make sure values like ``true`` and ``nil`` are converted to Python values correctly

.. code-block:: python
   :in-file: reader.py
   :in-slot: read_atom

   def read_atom(reader: Reader):
       tok = reader.next()
       if tok in {'(', ')'}:
           raise RuntimeError(f"Expected atom, got {tok!r}")

       with contextlib.suppress(ValueError):
           return int(tok)

       match tok:
           case 'true':
               return True
           case 'false':
               return False
           case 'nil':
               return None
           case _:
               return S(tok)

Printer
-------

Similarly, the printer needed to be tweaked to convert Python values to the correct string.

.. code-block:: python
   :in-file: printer.py

   def print_form(form):
       match form:
          case [*fs]:
              inner = " ".join(print_form(f) for f in fs)
              return f"({inner})"
          case True:
              return 'true'
          case False:
              return 'false'
          case None:
              return 'nil'
          case _:
              return str(form)

**repl**

.. code-block:: python
   :in-file: step4_if_fn_do.py
   :in-slot: repl

   def repl(input_: io.TextIO):
       env = Env()
       for symb, val in ns.items():
           env.set(symb, val)

       print("user> ", end='', flush=True)
       while (line := input_.readline()) != "":
           try:
               print(print_(evaluate(read(line), env)))
           except EOFError:
               print(f"EOF")
           except KeyError as e:
               print(f"{e.args[0]!r} not found")

           print("user> ", end='', flush=True)
