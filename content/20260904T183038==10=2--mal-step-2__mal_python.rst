Step 2: Evaluation
==================


Environment
-----------

This step introduces the environment.
The environment is where symbols are associated with values - which can include functions

.. code-block:: python
   :in-file: step2_eval.py
   :in-slot: env

   env = {
     '+': lambda a,b: a+b,
     '-': lambda a,b: a-b,
     '*': lambda a,b: a*b,
     '/': lambda a,b: int(a/b)
   }

Symbols
"""""""

Symbols are converted to their associated value within the environment.

.. code-block:: python
   :in-file: step2_eval.py
   :in-slot: eval_symbol

   case S(name):
       return env[name]

which requires us to tweak the definition of the ``S`` class to make it "match-able"

.. code-block:: python
   :in-file: reader.py
   :in-slot: symbol

   class S:
       __match_args__ = ("name",)

       def __init__(self, name: str):
           self.name = name

       def __repr__(self):
           return self.name

Lists
"""""

An empty list evaluates to itself.

.. code-block:: python
   :in-file: step2_eval.py
   :in-slot: eval_list

   case []:
       return []

Otherwise the first element is treated as a function with the remaining elements as its arguments.

.. code-block:: python
   :in-file: step2_eval.py
   :in-slot: eval_list

   case [*fs]:
    f, *args = [evaluate(f, env) for f in fs]
    return f(*args)

**repl**

.. code-block:: python
   :in-file: step2_eval.py
   :in-slot: repl

   def repl(input_: io.TextIO):
       print("user> ", end='', flush=True)
       while (line := input_.readline()) != "":
           try:
               print(print_(evaluate(read(line), env)))
           except EOFError:
               print(f"EOF")
           except KeyError as e:
               print(f"undefined symbol {e.args[0]!r}")
           print("user> ", end='', flush=True)
