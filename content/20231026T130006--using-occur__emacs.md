# Using Occur

## Editing

1. Hit `e` to make the ``occur`` buffer editable

2. Use the full power of Emacs to make your changes

3. Hit `C-c C-c` to commit the changes

[Searching and Editing Buffers with Occur Mode](https://www.masteringemacs.org/article/searching-buffers-occur-mode)
